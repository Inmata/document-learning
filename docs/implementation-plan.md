# 实施记录

每个工作包先验证可观察行为，再集成。公开包不附带个人会话、规则或技能内容。

1. 存储与经验：独立个人库、锁与事务、证据验证、条件匹配、局部例外、撤销、去重和回退。验证一百次偏好不能覆盖当前反向要求。
2. 自动入口（0.3.0 起）：hooks 只做会话提示与明确“记住”；后台计划任务扫描会话记录，Jev 预筛、整理模型提炼、程序校验后编译三层手册，晋升经用户确认。保留现有 hooks 的安装卸载。0.2.0 的逐轮回执与恢复票据已移除。
3. 技能维护：已匹配共享经验注入、管理区自动发布、调用边界、自包含生成及手动修改检测。覆盖新技能、现有技能和失配用例。
4. 历史：多源导入、Git 内容筛选、初始快照、前缀回放、冻结对照、检查点、断点继续和自动回补。通过混合提交及含未来答案的数据验证隔离。
5. 交付：虚构完整示例、中文使用文档、打包检查、真实会话导入与有依据的补学；本机可用入口安装和状态诊断。
