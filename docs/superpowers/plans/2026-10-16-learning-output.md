# 历史学习与个人技能产出实施计划

**目标：**把真实会话与技能提交整理成有来源、能调用、能检查效果的个人文档能力。

**已确认约束：**个人内容归插件数据目录；原 skills 仓库只读；公开程序不得含私人材料；旧技能显式调用政策不变；当前需求优先；不能以条数宣称效果。

- [ ] 拆分只读来源仓库与个人技能发布目录，迁移旧绑定，自动维护双宿主入口；回归同名冲突和手动修改保护。
- [ ] 修复原始日志导入，排除环境注入，保留角色、时间、工具来源；补齐三个指定会话。
- [ ] 新增当前资料补学：完整用户证据、当前技能与参考规则、相关提交差异；与严格时间回放分开标记，校验证据后生成个人规则与技能。
- [ ] 按用途筛选跨任务方法；原规则保留归档与回退；自动导出可阅读经验、案例及技能目录。
- [ ] 增加跨会话学习恢复票据和完成时技能维护判断，限制每次恢复数量，避免执行旧业务任务。
- [ ] 真实资料补学，发布个人技能，测试新会话发现、跨对象方法迁移、当前相反偏好、图片引用联动检查；报告输入和实际结果。
- [ ] 完成全量测试、包检查、隐私检查；集成回已安装仓库并核对原技能仓库无变更。
