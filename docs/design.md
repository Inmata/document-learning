# 文档持续学习插件设计

公开项目只包含程序、入口和虚构测试资料；真实会话及个人内容位于项目外。首版同时提供 Codex 与 Claude Code 原生入口，以命令型 hooks 启动，使用当前会话模型判断，不默认增加后台模型请求。

## 已确定行为

- 每个需求执行轻量判断；文档任务在计划前检索经验，完成前提交学习回执。Stop 只补偿一次，失败保留待处理状态，压缩、恢复及跨工作区继续使用同一绑定。
- 经验保留来源、适用条件、要求强度及例外。可信度、范围、强度独立；次数和用户沉默不能扩大偏好范围。当前要求优先，未解释的矛盾保留为条件未知。
- 方法、偏好、事实、调用政策分开保存。共享方法可由不同专业技能按需使用，案例参数不因相似任务自动搬运。已有技能的调用政策保持不变，不在插件内置个人技能名或偏好。
- 有证据且边界检查通过的技能自动创建或更新；不要求逐条批准。正文手动编辑受保护，自动内容使用带内容指纹的管理区。每次变更可查看、回退。
- 默认个人库位于用户数据目录，绑定存在但不可访问时报错，不初始化另一个库。外部技能仓库只读；个人生成技能写 library/skills，自动连接已安装宿主的技能入口。旧写入绑定备份后迁移为来源绑定。
- 历史导入接受 Codeg 精简记录、Codex/Claude JSONL 和规范化 JSON。保留缺失标记；Git 按文件内容与路径筛选，混合提交按文件拆分，重命名不当作新增经验。
- 历史补学可读当前状态；时间回放只给学习方前缀、初始快照和此前的演化结果。评估期望与未来提交不进学习输入。旧用户反馈只验证历史学习决策，不冒充新输出的用户评价。
- 回放分冻结初始、自动演化、实际维护参考。分项报告路由、错误学习、适用范围、调用边界、缺失与成本；没有文档快照时不声称版式改善。
- 本地写回、回退和可选 Git 版本；不自动推送，不上传原始记录，不把自动提交或回放记录算作新的用户证据。
- 宿主后台模型调用（ambient 建议、审批复核等）运行在非持久化线程上，载荷中 `transcript_path` 为 `null`；此类调用不建立会话、不建轮、不注入指导，只汇总忽略次数供 `doctor` 审计。判据只认显式 `null`，字段缺失或 Claude Code 的恒定路径均按普通会话处理。会话状态按容量修剪，仅淘汰全部轮已终结、无租约且无恢复票据的旧会话。

## 首版实现边界

Node.js 24，零运行时依赖；文件存储、跨进程锁、原子替换和事务快照。原生 hooks 使用同一程序，安装保留其他 hooks，卸载只移除本插件内容。提供实际 Claude Code JSON 后端与可配置 JSON 命令后端供历史运行；实时路径使用当前模型，无额外密钥。

宿主 hooks 的调用与模型遵从分别检测。插件安装不能代替 Codex 原生 hook 信任，也不能绕过工作区写权限。诊断显示真实回调和回执状态。
