# 文档持续学习插件设计

公开项目只包含程序、入口和虚构测试资料；真实会话及个人内容位于项目外。同时提供 Codex 与 Claude Code 原生入口。流程是“自动记录 → 批量整理 → 编译手册”：hooks 只登记会话并给出一行指导，后台按阈值批量整理宿主会话记录，整理结果编译为分层手册供写文档时读取。

## 已确定行为

- 当前会话不提交学习信号。hooks 登记请求与问答回答（供 `remember` 和晋升确认引用），SessionStart/SessionEnd 在后台触发 `consolidate --if-due`。后台整理按文件水位增量扫描 `~/.claude/projects` 与 `~/.codex/sessions`，排除配置路径和整理器自身会话；待整理会话达到 `minSessions`，或非空且超过 `maxWaitHours` 时才调用模型，持有独占锁，超过 3 天未整理时 SessionStart 提示。
- 整理先由 Jev（可关闭）丢弃高置信的非文档会话，再由 `claude --bare -p` 判断文档会话、提炼逐字引用的经验、合并重复证据并提出晋升提案。程序先演练校验引文与范围，失败带错误重试最多 3 次；每次运行保存输入、结果和 `report.md`。只有被经验引用的消息存入个人库。
- 经验分核心、文档类型、单份文档三层。晋升只能扩大到覆盖足够文档数的范围，需要用户在问答工具中确认并引用该回答；来源经验标为 superseded，后续证据并入新经验。用户明确要求记住时由 `remember` 立即入库。
- 经验保留来源、适用条件、要求强度及例外。可信度、范围、强度独立；次数和用户沉默不能扩大偏好范围。当前要求优先，未解释的矛盾保留为条件未知。
- 方法、偏好、事实、调用政策分开保存。共享方法可由不同专业技能按需使用，案例参数不因相似任务自动搬运。已有技能的调用政策保持不变，不在插件内置个人技能名或偏好。
- 有证据且边界检查通过的技能自动创建或更新；不要求逐条批准。正文手动编辑受保护，自动内容使用带内容指纹的管理区。每次变更可查看、回退。
- 默认个人库位于用户数据目录，绑定存在但不可访问时报错，不初始化另一个库。外部技能仓库只读；个人生成技能写 library/skills，自动连接已安装宿主的技能入口。旧写入绑定备份后迁移为来源绑定。
- 历史导入接受 Codeg 精简记录、Codex/Claude JSONL 和规范化 JSON。保留缺失标记；Git 按文件内容与路径筛选，混合提交按文件拆分，重命名不当作新增经验。
- 历史补学可读当前状态；时间回放只给学习方前缀、初始快照和此前的演化结果。评估期望与未来提交不进学习输入。旧用户反馈只验证历史学习决策，不冒充新输出的用户评价。
- 回放分冻结初始、自动演化、实际维护参考。分项报告路由、错误学习、适用范围、调用边界、缺失与成本；没有文档快照时不声称版式改善。
- 本地写回、回退和可选 Git 版本；不自动推送，不上传原始记录，不把自动提交或回放记录算作新的用户证据。
- 宿主后台模型调用（ambient 建议、审批复核等）运行在非持久化线程上，载荷中 `transcript_path` 为 `null`；此类调用不建立会话、不注入指导，只汇总忽略次数供 `doctor` 审计。会话状态按容量修剪。

## 首版实现边界

Node.js 24；运行时依赖只有固定版本的 `@jkudish/jev-agent-tools`。文件存储、跨进程锁、原子替换和事务快照。原生 hooks 使用同一程序，安装保留其他 hooks，卸载只移除本插件内容。配置文件 `config.json` 位于数据目录，无效值报错并指出字段；Windows 计划任务在 `install --schedule` 确认后创建，卸载时删除。

Jev 凭据只从环境变量读取（`TYPESAFE_API_KEY`、`OPENROUTER_API_KEY` 等），不写入文件或日志；缺少凭据或调用失败时回退为整理模型独立判断并记入报告。

手册 `knowledge/core.md`、`knowledge/<kind>.md`、`knowledge/conditional.md` 与 `knowledge/index.md` 按 required、default、suggestion，再按覆盖文档数和证据数排序，单个手册超过 `manual.maxChars` 时截断并注明。单份文档层经验只进 `cases/`。个人技能管理区只保留一行指向对应手册。

原生 AskUserQuestion 和 Codeg 问答只从真实返回值提取回答，按工具调用 ID 和问题序号登记独立用户来源，问题及未选选项不作为引文；拒答、空结果和自动超时不生成来源。

Claude Code 的模型工具调用另受权限规则和自动模式分类器审查。安装选项 `--allow-claude-signal` 只授权绝对脚本路径下的 `remember` 子命令，规则所有权独立登记；普通安装不新增权限。
